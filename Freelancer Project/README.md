# Item Management REST API

## Description
This is a simple Java Spring Boot REST API for managing items like an e-commerce system.

## Features
- Add a new item
- Get item by ID
- In-memory storage using ArrayList

## Technologies Used
- Java
- Spring Boot
- Maven

## How to Run
1. Open project in Spring Tool Suite
2. Run as Spring Boot Application
3. Access API at: http://localhost:8080/items

## API Endpoints

POST /items
GET /items/{id}
